# Live differential: unsigned completion plan

`npm run differential:plan` compiles the existing Clean, OriginHint and Counter probes with the pinned, hash-checked Solidity 0.8.24 compiler, checks their source and bytecode against the local ledger, verifies Hadrian chain ID 200010, and requests read-only deployment gas estimates. Its output is [`evidence/unsigned-differential-plan.json`](../evidence/unsigned-differential-plan.json). It never signs or sends.

The JSON contains full creation and runtime bytecode, exact call calldata and projected contract addresses for account `0x765fb7e6a0BdDDc29f57eeCE34AEda0Fb318805d` at pending nonces 4, 5 and 6. The projected addresses change if another transaction consumes a nonce or the order changes. At block 519636893, deployment gas estimates were Clean `3494881`, OriginHint `2296001`, Counter `3271361`; padded gas limits were `4543345`, `2984801`, `4252769`. At the sampled gas price, the combined deployment estimate ceiling was `2.009708440338224100` test USDC against the observed `11.733611224783532832` balance. Calls are additional, and their gas/fees cannot be quoted against undeployed addresses. These are dated estimates, not spending authorization. The planner also confirms that the three projected addresses have no code at the time of the check.

Start the local app with `npm.cmd run dev -- --hostname 127.0.0.1 --port 3000` and open `http://127.0.0.1:3000/hadrian/metamask` in a browser with the owner's MetaMask. Click **Connect MetaMask**. The six cards unlock in this exact order: **Deploy Clean**, **Deploy OriginHint**, **Deploy Counter**, **Call Clean**, **Call OriginHint**, **Call Counter**. On each card click **Refresh estimate**, compare account, chain ID, nonce, target, calldata, gas limit and maximum fee, tick the confirmation box, then click **Confirm in MetaMask** and approve only that one transaction in MetaMask. Wait for its verified receipt before moving to the next card. If it remains pending, click **Check receipts and save evidence**; never resend a pending step. To preserve projected deployment addresses, make no unrelated account transaction between the three deployments. Stop and regenerate the plan if nonce, address or fee changes. The local API rechecks each real receipt, transaction input, exact deployed runtime code, event and state/readback, then saves the hash to `evidence/differential-transactions.json` and refreshes `evidence/live-differential.json`. `npm.cmd run differential:verify` independently rechecks the saved hashes. No private key or automatic transaction is used.
